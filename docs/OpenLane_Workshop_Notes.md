# OpenLane Workshop Notes

## Introduction

The VSD OpenLane Workshop provided a beginner-friendly introduction to the ASIC physical design flow. Throughout the workshop, I learned how a RTL design is converted into a physical chip layout using the OpenLane tool and Sky130 PDK.

In addition to understanding the design flow, I also explored Linux commands, Docker, OpenLane and Magic Layout.

---

# What is OpenLane?

OpenLane is an open-source ASIC design flow used to automate different stages of digital chip design. It combines several open-source tools into a single flow, making it easier to move from RTL to a final physical layout.

During the workshop, OpenLane was mainly used in interactive mode to run different stages of the design flow.

---

# Sky130 PDK

A Process Design Kit (PDK) contains the technology files required to manufacture a chip.

The workshop used Sky130 PDK which is an open-source 130 nm process developed by SkyWater Technology.

---

# RTL to GDSII Flow

The complete ASIC design flow consists of several stages.

## 1. RTL Design

The design starts with Verilog code which describes the behaviour of the digital circuit.

---

## 2. Logic Synthesis

Logic synthesis converts the RTL design into a gate-level netlist using standard cells available in the technology library.

In OpenLane:

```tcl
run_synthesis
```

---

## 3. Floorplanning

Floorplanning defines the chip area and determines where standard cells, I/O pins and power connections will be placed.

In OpenLane:

```tcl
run_floorplan
```

---

## 4. Placement

Placement arranges all the standard cells inside the floorplan while trying to improve the overall layout.

In OpenLane:

```tcl
run_placement
```

---

## 5. Clock Tree Synthesis (CTS)

During this stage, the clock signal is distributed across the design so that different parts of the circuit receive the clock in a balanced manner.

In OpenLane:

```tcl
run_cts
```

---

## 6. Routing

Routing creates the metal connections between all the placed standard cells while following the design rules of the technology.

In OpenLane:

```tcl
run_routing
```

---

## 7. GDSII Generation

The final output of the physical design flow is the GDSII file, which represents the chip layout and is used for fabrication.

---

# Magic Layout

Magic is an open-source layout viewer and editor.

During the workshop, it was mainly used to:

- Open layouts generated by OpenLane
- View floorplans and placed cells
- Navigate through different layout levels
- Perform basic DRC exercises

---

# Design Rule Check (DRC)

A Design Rule Check (DRC) verifies whether a layout follows the manufacturing rules of the technology.

If any rule is violated, Magic highlights the error so that it can be identified and corrected.

---

# Important Files

During the workshop, I came across several file formats:

- **Verilog (.v)** – RTL design files.
- **LEF (.lef)** – Contains information about standard cells and technology.
- **DEF (.def)** – Describes the physical layout of the design.
- **GDSII (.gds)** – Final layout used for fabrication.
