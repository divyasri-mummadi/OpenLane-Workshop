# Magic Layout and DRC

## Introduction

Magic is an open-source layout editor and viewer used in VLSI design. During the workshop it was used to visualize layouts generated by OpenLane and perform basic DRC exercises.

---

## What is Magic?

Magic allows users to:

- View physical layouts
- Navigate through different layout levels
- Zoom and inspect standard cells
- Perform Design Rule Check (DRC)

---

## Opening Magic

To launch Magic for viewing the generated floorplan:

```bash
magic -T <path_to_sky130A.tech> lef read ../../tmp/merged.lef def read picorv32a.floorplan.def
```

For the DRC exercises provided during the workshop:

```bash
magic -d XR
```

---

## Design Rule Check (DRC)

DRC verifies whether a layout follows the manufacturing rules defined by the technology.

If a rule is violated, Magic highlights the error so that it can be identified and corrected before fabrication.

---

## DRC Exercises

During the workshop, Magic was used to:

- Open the provided layout files
- Identify DRC violations
- Understand common layout rules
- Learn how layout errors are detected
