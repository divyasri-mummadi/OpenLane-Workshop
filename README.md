- Ubuntu
- Docker
- OpenLane
- Magic
- Sky130 PDK


## RTL to GDSII Flow

The OpenLane flow followed during the workshop consists of the following stages:

1. RTL Design
2. Logic Synthesis
3. Floorplanning
4. Placement
5. Clock Tree Synthesis (CTS)
6. Routing
7. GDSII Generation


## Magic Layout

Magic was used to visualize layouts generated by OpenLane and to perform basic Design Rule Check (DRC) exercises. It helped in understanding how the physical layout of a digital design is represented.

Some of the activities performed include:

- Viewing floorplan layouts
- Exploring placed standard cells
- Navigating the layout hierarchy
- Understanding layout components
- Performing basic DRC exercises
